# MacWin

一款轻量级 macOS 菜单栏工具，为 Dock 应用增加“单击呼出／再次单击最小化”功能。

## 功能

- 单击 Dock 中的应用图标：呼出并置前窗口。
- 应用已经在前台时再次单击：最小化窗口。
- 支持微信、浏览器、访达等允许辅助功能控制的应用。
- 菜单栏“设置…”可选择“全部窗口”或“当前窗口”模式。
- 可选启用“点击空白桌面时最小化所有窗口”：仅拦截空白墙纸左键，不影响桌面图标、窗口、Dock 或右键。
- 菜单栏提供“录屏隐私模式”：一键最小化可访问窗口，并临时隐藏全局桌面小组件。

## 安装与运行

当前仓库提供源码，适合个人使用和测试。构建需要 macOS 13 或更高版本，以及 Xcode Command Line Tools。

```zsh
./src/toggle-dock-demo/scripts/build-app.sh
```

构建脚本会自动安装到 `/Applications/MacWin.app` 并启动。首次运行会弹出授权引导；也可在“系统设置 → 隐私与安全性 → 辅助功能”中启用 MacWin。

在菜单栏点击 MacWin 图标，选择“设置…”，可以查看授权状态、打开辅助功能设置，并开启“登录时自动启动 MacWin”。
获得辅助功能授权后，MacWin 不会再主动弹出授权提醒；设置页中的权限区域仅供手动查看或重新授权。
首次授权完成并返回 MacWin 后，会提示“立即重启”；确认后应用会自动重启并开始监听 Dock 点击。

如需启用“点击空白桌面时最小化所有窗口”，在 MacWin“设置…”中打开同名开关，并在确认弹窗中选择“自动设置并启用”。MacWin 会将“系统设置 → 桌面与程序坞 → 显示桌面”改为“仅在台前调度时点按”；它不会自动更改台前调度状态。若自动设置失败，MacWin 会打开系统设置供手动完成。拇指与三指张开显示桌面、Mission Control 等触控板手势不受此设置影响。

录屏前可在菜单栏点击 MacWin 图标，选择“进入录屏隐私模式…”。确认后，MacWin 会记录当前全局桌面小组件显示状态、隐藏桌面小组件并最小化可访问窗口；选择“退出录屏隐私模式”或退出 MacWin 后会恢复原状。该模式不改变台前调度、不切换桌面空间，也不能为不同桌面分别设置小组件。

## 注意事项

- 通过 macOS 辅助功能 API 控制窗口，不修改目标应用代码。
- 重建或更换签名后，可能需要重新授予辅助功能权限。
- 当前为本地 ad-hoc 签名版本，仅适合个人测试；对外分发需要 Developer ID 签名和 Apple 公证。
- 个别应用或特殊窗口可能不提供可操作的辅助功能接口。
- 空白桌面点击功能只最小化可访问且支持最小化的普通窗口；全屏、系统窗口或拒绝辅助功能控制的窗口会被跳过。
- 录屏隐私模式的小组件隐藏是 macOS 的全局显示偏好：进入期间所有桌面空间都会隐藏桌面小组件，退出后恢复进入前状态。
- 自动配置使用当前 macOS 的用户偏好项；macOS 更新后如该项失效，MacWin 会保留手动设置的回退路径。
