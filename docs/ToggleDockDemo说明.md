# MacWin

## 已实现

- 作为无 Dock 图标、无主窗口的菜单栏后台控制器运行。
- 授予辅助功能权限后，直接识别用户点击的 Dock 应用图标，不需要修改微信或其他目标应用的代码。
- 目标应用在后台、隐藏或窗口已最小化时：首次点击会恢复窗口并置前。
- 目标应用已在前台时：再次点击会最小化其可访问窗口；该次点击会被拦截，避免 Dock 默认行为立即重新打开刚最小化的窗口。
- Finder 多窗口：Finder 位于前台且有普通窗口时，一次点击最小化全部普通窗口；全部最小化后，每次点击只恢复窗口列表中的第一个窗口，再次点击将其最小化。
- 事件监听被 macOS 暂停时会自动恢复，避免后续 Dock 点击失去响应。
- 菜单栏“设置…”可选择“全部窗口”或“当前窗口”模式。
- 菜单栏“设置…”可选启用“点击空白桌面时最小化所有窗口”。该功能仅在没有普通窗口或桌面图标的位置拦截左键，并最小化所有可访问、可最小化的窗口。
- 菜单栏提供“录屏隐私模式”：确认后最小化可访问窗口，并在录屏期间临时隐藏全局桌面小组件。

## 启用 Dock 单击

1. 运行构建脚本，自动安装并启动 `/Applications/MacWin.app`。
2. 前往“系统设置 > 隐私与安全性 > 辅助功能”。
3. 点击“+”，选择 `MacWin.app`，再打开其开关。
4. 重新启动控制器；菜单栏会显示其状态图标。现在可以直接点击任一应用的 Dock 图标进行测试。

设置窗口提供“打开辅助功能设置”按钮，并可启用“登录时自动启动 MacWin”。

## 启用空白桌面点击最小化全部

1. 在 MacWin 菜单栏图标中选择“设置…”。
2. 打开“点击空白桌面时最小化所有窗口”。
3. 在确认弹窗中选择“自动设置并启用”。MacWin 会将“显示桌面”改为“仅在台前调度时点按”。
4. 左键点击没有 Finder 图标的空白墙纸，验证全部可访问窗口被最小化。

该开关默认关闭。MacWin 不会自动更改台前调度；若台前调度已开启，其专属的墙纸点击行为仍可能与本功能冲突，建议由用户自行关闭台前调度。自动设置失败时，MacWin 会打开系统设置供手动回退。系统触控板的“显示桌面”和 Mission Control 手势不受影响。

## 使用录屏隐私模式

1. 在菜单栏点击 MacWin 图标，选择“进入录屏隐私模式…”。
2. 在确认弹窗中选择“进入隐私模式”。MacWin 会保存当前小组件显示状态，隐藏桌面小组件，并最小化可访问窗口。
3. 录屏结束后，在同一菜单中选择“退出录屏隐私模式”；或者退出 MacWin，系统会恢复进入前的小组件状态。

该模式不会修改台前调度开关或切换桌面空间。macOS 的桌面小组件显示设置是全局的，因此录屏期间所有空间的小组件都会隐藏，不能按空间分别配置。

## 运行方式

在项目根目录执行：

```zsh
./src/toggle-dock-demo/scripts/build-app.sh
```

## 已知平台边界

PoC 使用公开辅助功能 API 在点击位置定位 Dock 图标，并用事件监听处理点击。仅当目标应用允许辅助功能接口读取、操作其窗口时，才能完成切换；不支持此类窗口的应用会保留 macOS 默认 Dock 行为。Dock 的辅助功能层级也可能随 macOS 版本和 Dock 布局变化，正式版本仍需兼容性测试。

当前包为本地 ad-hoc 签名。更换应用包、路径或签名后，macOS 可能要求重新授予辅助功能权限；对外分发需要 Developer ID 签名和 Apple 公证。

## 本机验证

v1.5 已在本机由用户完成 Dock 实际点击测试：微信及其他现有应用均可首次点击呼出并置前、再次点击最小化，且窗口不会立即弹回；Finder 多窗口的“全部最小化、单窗口恢复”规则也已验证。

v1.9 已完成 Release 编译、应用打包、安装和签名验证；录屏隐私模式的真实系统行为确认待用户在菜单栏确认后执行。空白桌面真实点击仍需要由用户在确认自动设置后进行端到端确认。
